## Template for a new company
Create `06_company_specific/<company_role>/README.md` with:
1. The job description link + key requirements
2. The interview process (rounds, format), from the recruiter, Glassdoor, or LeetCode Discuss
3. Values/culture to map stories to (e.g., Amazon LPs, Google "Googleyness")
4. Company-tagged coding problems (LeetCode → filter by company)
5. Likely system design questions (their products: e.g., Uber → ride matching)
6. Questions to ask, and why this company
