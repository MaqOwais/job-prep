# job-prep

My interview prep for **software engineering, system design, coding, and behavioral rounds**. Each topic has its own folder, and everything is ordered **Easy → Medium → Hard**.

System design content follows the structure of Donne Martin's [System Design Primer](https://github.com/donnemartin/system-design-primer) (CC BY 4.0) and links to its exact sections and solutions.

---

## 🚀 Start here
1. Read [00_start_here/study_plan.md](00_start_here/study_plan.md), the 8-week day-by-day plan.
2. Check things off in [00_start_here/progress_tracker.md](00_start_here/progress_tracker.md) as you go.
3. Every day, do **coding + system design + 1 behavioral story**. That's the whole routine.

## 🔑 Golden rules
- **Coding:** Clarify, give examples, explain brute force, optimize, code, test, analyze complexity. Talk the whole time.
- **System design:** Requirements, estimates, API, data model, high-level design, deep dive, bottlenecks. Always state tradeoffs.
- **Behavioral:** Use STAR. Say "I", not "we". Give numbers. End with what you learned.
- **Spaced repetition:** Redo every problem you couldn't solve **3 days later, then 7 days later**.
